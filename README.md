# Genshin Impact Gacha Calculator (원신 가챠 가능 횟수 및 반천장 계산기)

사용자가 직접 고안한 가챠 수식을 기반으로 작성된 원신 반천장 및 페이백(스타글리터) 계산 프로그램입니다.

## 📐 계산 수식 원리

### 변수 정의
- **$x$**: 가진 뽑기 수 (얽혀있는 인연 / 원석)
- **$l$**: 현재 누적된 스택 수
- **$a$**: 반천장 목표 가정 수치 (기본 80회)
- **$n$**: 반천장 가능 횟수
- **$q$**: 반천 후 남는 나머지 뽑기 수
- **$P$**: 페이백(스타글리터)으로 얻는 추가 인연 수
- **$m$**: 추가 뽑기 수 ($P + q$)
